Getting started with the Microsoft Graph PowerShell SDK

Updated: 2026-11-22

Warning

The steps in this article are based on Microsoft Graph PowerShell SDK 1.6.1. Authentication methods and command parameters may differ in the current SDK. For the latest steps, see the installation and authentication documentation. Azure Active Directory is now called Microsoft Entra ID.

One way to use Microsoft Graph is with the Microsoft Graph PowerShell SDK. PowerShell makes it relatively easy to use REST APIs such as Microsoft Graph even without an SDK, but the SDK is an option if you want to write as little code as possible.

The Microsoft Graph PowerShell SDK is already generally available, but some implementations are unstable, so be careful. It supports the whole of Microsoft Graph, so installing it makes a large number of commands available. The PowerShell modules are also separated by resource and other categories, so many modules are installed. You can also use only specific modules. In many scenarios, most of these commands will not be used. You should therefore consider whether to use the Microsoft Graph PowerShell module or implement the rest with standard PowerShell features, even if you use MSAL for OAuth.

I tested the steps in the following environment. With this SDK version, Windows PowerShell causes problems with request query strings, so I tested with PowerShell 7 instead of Windows PowerShell.

  • Microsoft Graph PowerShell SDK 1.6.1
  • PowerShell 7.1.4

About the Microsoft Graph PowerShell SDK

The Microsoft Graph PowerShell SDK is an open-source PowerShell module that makes it easier to use Microsoft Graph from PowerShell. The project is managed on GitHub, and the PowerShell module is distributed under the MIT license. Unlike a paid product, it is distributed for free under the MIT license, so Microsoft technical support may be limited or may not be available depending on the issue.

The following documentation describes the basic process:

Use app-only authentication with the Microsoft Graph PowerShell SDK

First, register an application in Azure AD:

  1. Sign in to the Azure Portal.
  2. Select Azure Active Directory > App registrations > New registration.
  3. Enter a name for the application, such as App01.
  4. Under Supported account types, select Accounts in this organizational directory only.
  5. Under Redirect URI, select Web and leave the text box empty.
  6. Select Register.
  7. Note the displayed Application (client) ID and Directory (tenant) ID.
  8. Select Manage > API permissions > Add a permission.
  9. Select Microsoft Graph > Application permissions, select Mail.Read and User.Read.All, and then select Add permissions.
  10. Under Configured permissions, select the ellipsis next to the User.Read permission of type Delegated, and select Remove permission. When prompted, select Yes, remove.
  11. Select Grant admin consent for <tenant name>. When prompted, select Yes.
