Do You Really Need to Retrieve All Office 365 Audit Logs?

Note

This is the latest status as of October 2026. The Microsoft Graph auditLogQuery API for Microsoft Purview audit logs is now generally available. You can export up to 1 million audit records per query. Microsoft has also announced that the Search-UnifiedAuditLog command will be retired on October 15, 2027. After that date, the command will no longer provide access to audit logs. If you use Search-UnifiedAuditLog in scripts or automation, you need to migrate to the Microsoft Graph auditLogQuery API. The rest of this article is based on the content as of 2023, so read the parts about Search-UnifiedAuditLog with this status in mind.

Getting Started with the Office 365 Reporting Web Service

Warning

The Message Trace reports in the Office 365 Reporting Web Service described in this article were retired on April 8, 2026. Do not use this API for new implementations. For current message tracing, use Get-MessageTraceV2 and Get-MessageTraceDetailV2 in Exchange Online PowerShell, or the Microsoft Graph Message Trace API.
