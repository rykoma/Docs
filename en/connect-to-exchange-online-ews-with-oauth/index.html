Connect to Exchange Online EWS with OAuth

Warning

Starting October 1, 2026, Exchange Online is scheduled to block Exchange Web Services (EWS) requests from non-Microsoft applications. For new applications, consider alternatives such as Microsoft Graph based on your scenario. See Microsoft’s Retirement of Exchange Web Services in Exchange Online announcement for details.

Updated on November 25, 2020

This article originally described how to use OAuth to connect to EWS because Microsoft did not provide enough detailed instructions at that time. Microsoft now provides the following page, so I removed the original content from this article.
