A Script to Get Exchange Server Build Numbers

I created a script to get Exchange server build numbers and published it on GitHub. You can access it here. It works by searching a definition file, which I created based on the public information below, for the build number of the specified product version. I’d like to keep updating it whenever a new CU is released.

TITLE: Exchange Server updates: Build numbers and release dates
URL: https://learn.microsoft.com/en-us/exchange/new-features/build-numbers-and-release-dates

Let me briefly show you how to use it. It’s now published as a PowerShell Module named ExchangeBuildNumber, which you can install from the PowerShell Gallery.
