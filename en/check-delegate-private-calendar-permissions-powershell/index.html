Check delegate and private calendar permissions with PowerShell

Updated: 2026-10-10

Previously, you had to use Outlook or EWS to check delegate settings and whether a delegate could view private items. This capability is now available in Exchange Online PowerShell, but it applies only to calendar folders.

Note

This example is for Exchange Online. The Get-MailboxFolderPermission cmdlet itself is available in both Exchange Server and Exchange Online, but SharingPermissionFlags is available only in Exchange Online. This flag also applies to calendar folders. Do not assume that the same result is available in Exchange Server. See Microsoft Learn for Get-MailboxFolderPermission and the SharingPermissionFlags documentation.
