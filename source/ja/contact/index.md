お問い合わせは、次の 2 つの方法からお選びください。

## 記事の誤りや改善提案について

誤字脱字、事実誤認、リンク切れ、その他の改善提案は、GitHub の Issue フォームからご連絡ください。対象の記事のタイトルや URL を記載していただけると、対応がスムーズです。利用には GitHub アカウントが必要です。

[Issue を作成する (GitHub)](https://github.com/rykoma/Docs/issues/new?template=blog-feedback-ja.yml)

## それ以外のお問い合わせについて

上記以外のご連絡 (お仕事のご相談など) は、LinkedIn からご連絡ください。利用には LinkedIn アカウントが必要です。

[LinkedIn プロフィール](https://www.linkedin.com/in/rykoma/)
