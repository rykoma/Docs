> [!WARNING]
> Starting October 1, 2026, Exchange Online is scheduled to block Exchange Web Services (EWS) requests from non-Microsoft applications. For new applications, consider alternatives such as Microsoft Graph based on your scenario. See Microsoft's [Retirement of Exchange Web Services in Exchange Online](https://devblogs.microsoft.com/microsoft365dev/retirement-of-exchange-web-services-in-exchange-online/) announcement for details.

Updated on November 25, 2020

This article originally described how to use OAuth to connect to EWS because Microsoft did not provide enough detailed instructions at that time. Microsoft now provides the following page, so I removed the original content from this article.

[Authenticate an EWS application by using OAuth](https://learn.microsoft.com/en-us/exchange/client-developer/exchange-web-services/how-to-authenticate-an-ews-application-by-using-oauth)
